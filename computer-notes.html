Computer Fundamentals

A computer is an electronic system that accepts input, processes data, stores information and produces output.

Basic Cycle

  • Input
  • Processing
  • Storage
  • Output

Important Components

  • CPU — Central Processing Unit
  • RAM — temporary working memory
  • Storage — HDD / SSD
  • Motherboard — connects major components
🐍

Programming Fundamentals

Programming is the process of giving instructions to a computer to perform a task.

Core Concepts

  • Variables
  • Data types
  • Conditions
  • Loops
  • Functions
  • Algorithms

Python Example

name = "Anshu"
print("Hello", name)
🌐

Web Development

Web development involves creating websites and web applications that run through browsers.

The Three Core Technologies

  • HTML → structure
  • CSS → design and appearance
  • JavaScript → behaviour and interaction

Simple HTML

<h1>Hello World</h1>
<p>My website</p>
🌍

Computer Networking

A computer network allows devices to communicate and share information.

Important Terms

  • IP Address → identifies a device on a network
  • DNS → translates domain names to IP addresses
  • Router → forwards network traffic
  • HTTP/HTTPS → web communication protocols

Example

When you type a website address, DNS can help find the corresponding server address.

🔐

Cyber Security

Cybersecurity protects devices, networks, applications and information from unauthorized access or harmful activity.

Common Threats

  • Phishing
  • Malware
  • Weak passwords
  • Social engineering

Basic Safety

  • Use strong unique passwords
  • Enable multi-factor authentication where available
  • Keep software updated
  • Check suspicious links before opening them
🤖

Artificial Intelligence

Artificial Intelligence refers to computer systems designed to perform tasks that normally require aspects of human intelligence.

Related Areas

  • Machine Learning
  • Natural Language Processing
  • Computer Vision
  • Generative AI

Machine Learning

Machine learning uses data to train models that can identify patterns and make predictions or classifications.

Databases & SQL

A database is an organised collection of information that can be stored, managed and retrieved.

Database Concepts

  • Table
  • Row
  • Column
  • Primary Key
  • Query

SQL Example

SELECT * FROM students;

Cloud Computing

Cloud computing provides computing resources such as storage, servers and applications over a network, commonly the internet.

Examples of Cloud Services

  • Cloud storage
  • Cloud databases
  • Virtual servers
  • Web applications
⚙️

Operating Systems

An operating system manages computer hardware and provides services for applications and users.

Examples

  • Windows
  • Linux
  • Android
  • macOS

Main Responsibilities

  • File management
  • Memory management
  • Process management
  • Device management
