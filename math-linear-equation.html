📚 What is a Linear Equation?

A linear equation in one variable is an equation in which the highest power of the variable is 1.

General form: ax + b = 0, where a ≠ 0

The value of the variable that makes the equation true is called the solution of the equation.

🧠 Important Rules

• The same number can be added or subtracted from both sides.

• Both sides can be multiplied or divided by the same non-zero number.

• Terms can be transposed from one side to the other by changing their sign.

• Always verify the answer by putting it back into the original equation.

✍️ Solved Examples

Example 1:
Solve: 3x + 5 = 20

3x = 20 − 5
3x = 15
x = 5
Example 2:
Solve: 5x − 7 = 18

5x = 25
x = 5
Example 3:
Solve: 2x + 7 = x + 15

2x − x = 15 − 7
x = 8
Example 4:
Solve: 3(x + 2) = 21

x + 2 = 7
x = 5
