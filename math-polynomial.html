Polynomials

Complete Notes • Concepts • Identities • Examples • Quiz

📖 1. What is a Polynomial?

A polynomial in one variable is an algebraic expression in which the powers of the variable are non-negative integers and the coefficients are real numbers.

Example: 3x² + 5x - 7

Here, x is the variable and 3, 5 and -7 are the coefficients.

🔢 2. Terms of a Polynomial

The different parts of a polynomial separated by plus or minus signs are called terms.

Example:

5x³ - 4x² + 7x - 9

Terms are:
5x³, -4x², 7x and -9

Coefficient

The numerical factor multiplying a variable is called its coefficient.

In 7x², the coefficient of x² is 7.

📊 3. Degree of a Polynomial

The highest power of the variable in a polynomial is called its degree.

Example:

4x³ + 2x² - 5x + 8

Highest power = 3
Therefore, degree = 3

Special Cases

  • A non-zero constant polynomial has degree 0.
  • The zero polynomial has no defined degree.

🧩 4. Types of Polynomials

Constant Polynomial

5

Degree = 0

Linear Polynomial

ax + b

Degree = 1

Quadratic Polynomial

ax² + bx + c

Degree = 2

Cubic Polynomial

ax³ + bx² + cx + d

Degree = 3

🧮 5. Value of a Polynomial

To find the value of a polynomial for a particular value of the variable, substitute that value into the polynomial.

Example:

p(x) = x² + 3x + 2

Find p(2).

p(2) = (2)² + 3(2) + 2
= 4 + 6 + 2
= 12

🎯 6. Zero of a Polynomial

A number k is called a zero of a polynomial p(x) if p(k) = 0.

p(k) = 0
Example:

p(x) = x - 5

Put x = 5:
p(5) = 5 - 5 = 0

Therefore, 5 is the zero of the polynomial.

📐 7. Remainder Theorem

When a polynomial p(x) is divided by x - a, the remainder is p(a).

Remainder = p(a)
Example:

p(x) = x² + 3x + 2

Divide by x - 1.

Here a = 1.
p(1) = 1 + 3 + 2 = 6

Therefore, remainder = 6.

⭐ 8. Factor Theorem

If p(a) = 0, then x - a is a factor of p(x).

p(a) = 0 ⟹ (x - a) is a factor of p(x)
Example:

p(x) = x² - 5x + 6

p(2) = 4 - 10 + 6 = 0

Therefore, x - 2 is a factor.

⭐ 9. Important Algebraic Identities

Identity 1

(a + b)² = a² + 2ab + b²

Identity 2

(a - b)² = a² - 2ab + b²

Identity 3

(a + b)(a - b) = a² - b²

Identity 4

(x + a)(x + b) = x² + (a + b)x + ab

Identity 5

(x - a)(x - b) = x² - (a + b)x + ab

  • Find the zero of p(x) = x - 7.
  • Check whether x - 2 is a factor of x² - 5x + 6.
  • Expand (x + 5)².
  • Factorise x² - 25.

🔥 11. Exam Important Points

  • Degree means the highest power of the variable.
  • A linear polynomial has degree 1.
  • A quadratic polynomial has degree 2.
  • A cubic polynomial has degree 3.
  • The zero of p(x) is the value of x for which p(x) = 0.
  • For divisor x - a, remainder = p(a).
  • If p(a) = 0, then x - a is a factor of p(x).
  • Learn all important algebraic identities properly.
