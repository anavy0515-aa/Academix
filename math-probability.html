🎲 Basic Concept

Probability tells us how likely an event is to occur.

An experiment is an activity that produces an outcome.

An event is a collection of one or more outcomes.

Probability of an event = Number of favourable outcomes ÷ Total number of equally likely outcomes

🧠 Important Formula

P(E) = Number of favourable outcomes / Total number of outcomes

Probability always lies between 0 and 1 for the standard elementary cases.

0 ≤ P(E) ≤ 1

An impossible event has probability 0.

A sure event has probability 1.

🪙 Common Experiments

Coin: Head or Tail.

Die: 1, 2, 3, 4, 5 or 6.

Cards: Different cards from a deck.

✍️ Solved Examples

Example 1:

A fair coin is tossed once. Find probability of getting Head.

Favourable outcomes = 1
Total outcomes = 2

P(Head) = 1/2
Answer = 1/2
Example 2:

A die is thrown once. Find probability of getting 4.

Favourable outcomes = 1
Total outcomes = 6

P(4) = 1/6
Example 3:

A die is thrown. Find probability of getting an even number.

Even outcomes = 2, 4, 6 → 3 outcomes
Total = 6

P(Even) = 3/6
= 1/2
