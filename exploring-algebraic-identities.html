Exploring Algebraic Identities

Class 9 Mathematics · Chapter 4 · Worked Solutions

Quick Revision — Important Identities

1. (a + b)² = a² + 2ab + b²

2. (a − b)² = a² − 2ab + b²

3. (a + b)(a − b) = a² − b²

4. (x + a)(x + b) = x² + (a + b)x + ab

5. (a + b)³ = a³ + 3a²b + 3ab² + b³

6. (a − b)³ = a³ − 3a²b + 3ab² − b³

7. a³ + b³ = (a + b)(a² − ab + b²)

8. a³ − b³ = (a − b)(a² + ab + b²)

9. a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)

Exercise Set 4.1 — Visualising Algebraic Identities

Example

Expand (x + 5)².

Show Solution
(x + 5)² = x² + 2(x)(5) + 5²
= x² + 10x + 25
Practice

Expand (2x + 3)².

Show Solution
(2x + 3)² = (2x)² + 2(2x)(3) + 3²
= 4x² + 12x + 9
Practice

Evaluate 64² using an algebraic identity.

Show Solution
64² = (60 + 4)²
= 60² + 2(60)(4) + 4²
= 3600 + 480 + 16
= 4096

Exercise Set 4.2 — Factorisation Using Identities

Example

Factorise x² + 10x + 25.

Show Solution
x² + 10x + 25 = x² + 2(x)(5) + 5²
Using a² + 2ab + b² = (a + b)²:
Answer: (x + 5)²
Practice

Factorise 9x² − 16.

Show Solution
9x² − 16 = (3x)² − 4²
Using a² − b² = (a − b)(a + b):
Answer: (3x − 4)(3x + 4)
Practice

Calculate 193² using an identity.

Show Solution
193² = (200 − 7)²
= 200² − 2(200)(7) + 7²
= 40000 − 2800 + 49
= 37249

Exercise Set 4.3 — More Identities

Example

Expand (a + b + c)².

Show Solution
(a + b + c)² = (a + b + c)(a + b + c)
= a² + b² + c² + 2ab + 2bc + 2ca
Practice

Expand (x + y)³.

Show Solution
(x + y)³ = x³ + 3x²y + 3xy² + y³
Practice

Factorise a³ + b³.

Show Solution
Using the sum of cubes identity:
a³ + b³ = (a + b)(a² − ab + b²)

Exercise Set 4.4 — Splitting the Middle Term

Example

Factorise x² + 7x + 12.

Show Solution
Find two numbers whose sum is 7 and product is 12.
Those numbers are 3 and 4.
x² + 7x + 12 = x² + 3x + 4x + 12
= x(x + 3) + 4(x + 3)
= (x + 3)(x + 4)
Practice

Factorise x² − 5x + 6.

Show Solution
Two numbers with sum −5 and product 6 are −2 and −3.
x² − 5x + 6 = x² − 2x − 3x + 6
= x(x − 2) − 3(x − 2)
= (x − 2)(x − 3)
Practice

Factorise 2x² + 7x + 3.

Show Solution
2x² + 7x + 3 = 2x² + 6x + x + 3
= 2x(x + 3) + 1(x + 3)
= (2x + 1)(x + 3)

Exercise Set 4.5 — Rational Expressions

Example

Simplify (x² − 9)/(x − 3).

Show Solution
x² − 9 = (x − 3)(x + 3).
Therefore, for x ≠ 3:
(x² − 9)/(x − 3) = x + 3
Practice

Simplify (x² − 4)/(x + 2).

Show Solution
x² − 4 = (x − 2)(x + 2).
For x ≠ −2:
(x² − 4)/(x + 2) = x − 2

End-of-Chapter Exercise — Q1 to Q13

Q1

Expand (−3x + 4)².

Show Solution
(−3x + 4)² = 9x² − 24x + 16
Q1

Simplify (2s + 7)(2s − 7).

Show Solution
= (2s)² − 7²
= 4s² − 49
Q1

Simplify (p² + 1/2)(p² − 1/2).

Show Solution
= (p²)² − (1/2)²
= p⁴ − 1/4
Q2

Calculate 17 × 21 using an identity.

Show Solution
17 × 21 = (19 − 2)(19 + 2)
= 19² − 2²
= 361 − 4
= 357
Q2

Calculate 104 × 96 using an identity.

Show Solution
104 × 96 = (100 + 4)(100 − 4)
= 100² − 4²
= 10000 − 16
= 9984
Q3

Factorise x² − 16.

Show Solution
x² − 16 = x² − 4²
= (x − 4)(x + 4)
Q4

Simplify (x² − 25)/(x − 5).

Show Solution
x² − 25 = (x − 5)(x + 5).
For x ≠ 5, the expression simplifies to x + 5.
Q5

Find possible dimensions of a rectangle if its area is x² + 7x + 12.

Show Solution
x² + 7x + 12 = (x + 3)(x + 4).
Possible dimensions are x + 3 and x + 4.
Q6

Find possible dimensions of a cuboid whose volume is 2x² + 7x + 3 times a given third dimension.

Show Solution
2x² + 7x + 3 = (2x + 1)(x + 3).
These are factors of the polynomial; match them with the exact dimensions given in your textbook question.
Q7

A square playground has side 40 m. A path of width s surrounds it. Find the area of the path.

Show Solution
Outer square side = 40 + 2s.
Path area = (40 + 2s)² − 40²
= 1600 + 160s + 4s² − 1600
= 160s + 4s² m²
Q8

A number plus its reciprocal is 10/3. Find the number.

Show Solution
Let the number be x, where x ≠ 0.
x + 1/x = 10/3
3x² − 10x + 3 = 0
(3x − 1)(x − 3) = 0
Therefore, x = 1/3 or x = 3.
Q9

A rectangular pool has area 2x² + 7x + 3 square units and width 2x + 1 units. Find its length.

Show Solution
Length = area ÷ width
= (2x² + 7x + 3)/(2x + 1)
= ((2x + 1)(x + 3))/(2x + 1)
= x + 3 units, where 2x + 1 ≠ 0.
Q10

If x − 2 and x − 1/2 are factors of px² + 5x + r, prove that p = r.

Show Solution
Since both are factors, the roots are 2 and 1/2.
For px² + 5x + r, sum of roots = −5/p and product = r/p.
2 + 1/2 = 5/2 = −5/p, so p = −2.
Product = 1 = r/p, so r = p = −2.
Hence p = r.
Q11

Given a + b + c = 5 and ab + bc + ca = 10, evaluate a³ + b³ + c³ − 3abc.

Show Solution
Use the identity:
a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca).
Also, (a + b + c)² = a² + b² + c² + 2(ab + bc + ca).
25 = a² + b² + c² + 20, so a² + b² + c² = 5.
Thus the required expression = 5(5 − 10) = −25.
Q12

Prove that n³ − n is divisible by 6 for every natural number n.

Show Solution
n³ − n = n(n² − 1)
= n(n − 1)(n + 1).
These are three consecutive integers. One is divisible by 3 and at least one is even. Their product is divisible by 2 × 3 = 6.
Q13

If x + y = −4, find x³ + y³ − 12xy + 64.

Show Solution
Use x³ + y³ = (x + y)³ − 3xy(x + y).
Since x + y = −4:
x³ + y³ = −64 + 12xy.
Required expression = (−64 + 12xy) − 12xy + 64
= 0.
