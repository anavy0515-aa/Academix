Chapter 2: Introduction to Linear Polynomials

Class 9 Mathematics · Ganita Manjari · Worked Solutions

Chapter Overview

A polynomial is an algebraic expression whose variable powers are non-negative integers.

Linear polynomial:

p(x) = ax + b, where a ≠ 0

  • a is the coefficient of x.
  • b is the constant term.
  • The degree of a linear polynomial is 1.
  • Its zero is x = −b/a.

Exercise Set 2.1 — Polynomials and Degree

Question 1. Find the degree of each polynomial.

(i) 2x² − 5x + 3   (ii) y³ + 2y − 1   (iii) −9   (iv) 4z − 3

Show Solution

(i) Highest power is 2, so degree = 2.

(ii) Highest power is 3, so degree = 3.

(iii) A non-zero constant has degree 0.

(iv) Highest power is 1, so degree = 1.

Question 2. Give examples of polynomials of degrees 1, 2 and 3.

Show Solution

Degree 1: 3x + 2

Degree 2: x² + 5x + 1

Degree 3: 2x³ − x + 4

The degree is the highest power with a non-zero coefficient.

Question 3. Find the coefficients of x² and x³.

Polynomial: x⁴ − 3x³ + 6x² − 2x + 7

Show Solution

Rewrite the relevant terms as −3 × x³ + 6 × x².

Coefficient of x² = 6.

Coefficient of x³ = −3.

Question 4. Find the coefficient of z.

Polynomial: 4z³ + 5z² − 11

Show Solution

There is no term containing z to the first power. We can write its coefficient as 0.

Answer: 0.

Question 5. Find the constant term.

Polynomial: 9x³ + 5x² − 8x − 10

Show Solution

The constant term is the term without a variable.

Answer: −10.

Exercise Set 2.2 — Evaluating Polynomials

Question 1. Evaluate p(x) = 5x − 3 at x = 0, −1 and 2.

Show Solution

p(0) = 5(0) − 3 = −3.

p(−1) = 5(−1) − 3 = −8.

p(2) = 5(2) − 3 = 7.

Question 2. Evaluate p(s) = 7s² − 4s + 6.

Substitute the required value of s from your textbook into the expression.

Show Solution Method

For s = 0, p(0) = 7(0)² − 4(0) + 6 = 6.

For any other value k, p(k) = 7k² − 4k + 6.

Substitute each printed value of s to obtain its corresponding answer.

Question 3. A mother's present age is three times her son's age. In five years, their ages will total 70. Find their current ages.

Show Solution

Let the son's age be x. The mother's age is 3x.

After five years: (x + 5) + (3x + 5) = 70.

4x + 10 = 70, so 4x = 60 and x = 15.

Son = 15 years; mother = 45 years.

Question 4. Two positive integers differ by 63 and are in the ratio 2 : 5. Find them.

Show Solution

Let the integers be 2x and 5x.

5x − 2x = 63, so 3x = 63 and x = 21.

Answer: 42 and 105.

Question 5. Ruby has three times as many ₹2 coins as ₹5 coins. Their total value is ₹88. Find the number of each type.

Show Solution

Let the number of ₹5 coins be x. Then ₹2 coins = 3x.

Total value: 5x + 2(3x) = 88.

11x = 88, so x = 8.

Answer: 8 coins of ₹5 and 24 coins of ₹2.

Question 6. A 300-foot fence is split into two pieces. The longer piece is four times the shorter piece. Find both lengths.

Show Solution

Let the shorter piece be x feet. The longer piece is 4x feet.

x + 4x = 300, so 5x = 300 and x = 60.

Answer: 60 feet and 240 feet.

Question 7. A rectangle's length is three more than twice its width. Its perimeter is 24 cm. Find its dimensions.

Show Solution

Let the width be w cm. Length = 2w + 3.

Perimeter = 2(length + width) = 24.

(2w + 3) + w = 12.

3w + 3 = 12, so w = 3.

Length = 2(3) + 3 = 9 cm.

Answer: Length 9 cm, width 3 cm.

Exercise Set 2.3 — Exploring Linear Patterns

Question 1. A student starts with ₹500 and receives ₹150 each month. Find the amount after n monthly additions.

Show Solution

Initial amount = ₹500. Monthly addition = ₹150.

After n additions, amount = 500 + 150n.

After 1 month: ₹650; after 2 months: ₹800; after 3 months: ₹950.

Pattern: A(n) = 500 + 150n.

Question 2. A rally starts with 120 members and loses 9 members each hour. Find the number remaining after n hours.

Show Solution

Remaining members = initial members − members leaving.

M(n) = 120 − 9n.

After 1 hour: 111; after 2 hours: 102; after 3 hours: 93.

This model is meaningful while the calculated number of members is non-negative.

Question 3. A rectangle is 13 cm long. Find its area when the breadth is 12 cm, 10 cm and 8 cm. Form a pattern.

Show Solution

Area = length × breadth = 13b.

For b = 12: area = 156 cm².

For b = 10: area = 130 cm².

For b = 8: area = 104 cm².

Pattern: A = 13b.

Question 4. A rectangular box is 7 cm long and 11 cm wide. Find its volume for heights 5 cm, 9 cm and 13 cm.

Show Solution

Volume = length × breadth × height = 7 × 11 × h = 77h.

For h = 5: V = 385 cm³.

For h = 9: V = 693 cm³.

For h = 13: V = 1001 cm³.

Pattern: V = 77h.

Question 5. Sarita reads 20 pages each day from a 500-page book. How many pages remain after 15 days?

Show Solution

Pages remaining after n days = 500 − 20n.

After 15 days: 500 − 20(15) = 500 − 300 = 200.

Answer: 200 pages remain.

Exercise Set 2.4 — Linear Growth and Decay

Question 1. A plant is initially 1.75 feet tall and grows by 0.5 feet per month. Find its height after 7 months and form a model.

Show Solution

Height after t months: h = 1.75 + 0.5t.

After 7 months: h = 1.75 + 0.5(7) = 5.25 feet.

Values for months 0 to 10:

1.75, 2.25, 2.75, 3.25, 3.75, 4.25, 4.75, 5.25, 5.75, 6.25, 6.75 feet.

The height increases by a constant 0.5 feet each month.

Question 2. A phone costs ₹10,000 and loses ₹800 of value each year. Find its value after 3 years and form a model.

Show Solution

Value after t years: v = 10000 − 800t.

After 3 years: v = 10000 − 2400 = ₹7600.

Values from year 0 to year 8:

₹10,000; ₹9,200; ₹8,400; ₹7,600; ₹6,800; ₹6,000; ₹5,200; ₹4,400; ₹3,600.

The value decreases by ₹800 each year.

Question 3. A village has 750 people initially and gains 50 people each year. Find its population after 6 years.

Show Solution

Population after t years: P = 750 + 50t.

After 6 years: P = 750 + 50(6) = 1050.

Values for years 0 to 10: 750, 800, 850, 900, 950, 1000, 1050, 1100, 1150, 1200, 1250.

Question 4. A prepaid balance of ₹600 decreases by ₹15 per day. Form a model and find when it runs out.

Show Solution

Balance after x days: b(x) = 600 − 15x.

For the balance to become zero: 600 − 15x = 0.

15x = 600, so x = 40.

Answer: The balance runs out after 40 days.

For days 1–10 the balances are ₹585, ₹570, ₹555, ₹540, ₹525, ₹510, ₹495, ₹480, ₹465 and ₹450.

Exercise Set 2.5 — Linear Relationships

Question 1. A learning platform charges a fixed fee and a per-module fee. Bills are ₹400 for 10 modules and ₹500 for 14 modules. Find y = ax + b.

Show Solution

Using (x, y) = (10, 400) and (14, 500):

a = (500 − 400)/(14 − 10) = 100/4 = 25.

400 = 25(10) + b, so b = 150.

Model: y = 25x + 150.

Question 2. A gym bills ₹800 for 10 court-hours and ₹1100 for 15 court-hours. Find y = ax + b.

Show Solution

a = (1100 − 800)/(15 − 10) = 300/5 = 60.

800 = 60(10) + b, so b = 200.

Model: y = 60x + 200.

Question 3. Express Celsius temperature C as C = aF + b using the freezing and boiling points of water.

Show Solution

At F = 32, C = 0: 0 = 32a + b.

At F = 212, C = 100: 100 = 212a + b.

Subtracting equations: 100 = 180a, so a = 5/9.

b = −32(5/9) = −160/9.

C = (5/9)F − 160/9 = (5/9)(F − 32).

Exercise Set 2.6 — Visualising Linear Relationships

For each line, plot a few points and join them with a straight line.

Question 1(i). Compare y = 4x, y = 2x and y = x.

Show Solution

All three lines pass through (0, 0).

Their slopes are 4, 2 and 1 respectively.

All have y-intercept 0. The line with the larger positive slope rises more steeply.

Question 1(ii). Compare y = −6x, y = −3x and y = −x.

Show Solution

All pass through the origin. Their slopes are −6, −3 and −1.

Each line falls from left to right. The absolute value of the slope controls steepness.

Question 1(iii). Compare y = 5x and y = −5x.

Show Solution

Both pass through (0, 0). Their slopes are 5 and −5.

The first rises from left to right; the second falls. Both have the same steepness.

Question 1(iv). Compare y = 3x − 1, y = 3x and y = 3x + 1.

Show Solution

All have slope 3, so they are parallel.

The y-intercepts are −1, 0 and 1 respectively. Changing b shifts a line vertically.

Question 1(v). Compare y = −2x − 3, y = −2x and y = −2x + 3.

Show Solution

All have slope −2 and are parallel.

The y-intercepts are −3, 0 and 3 respectively.

The coefficient of x determines slope; the constant term determines the y-intercept.

End-of-Chapter Exercise

Question 1. Construct a cubic polynomial whose x² coefficient is −7.

Show Solution

A cubic polynomial has a non-zero x³ coefficient.

One example is p(x) = x³ − 7x² + 2x + 1.

Its degree is 3 and the coefficient of x² is −7.

Question 2. Evaluate the polynomials at the indicated values.

(i) 5x² − 3x + 7 at x = 1.

(ii) 4t³ − t² + 6 at t = a.

Show Solution

(i) p(1) = 5(1)² − 3(1) + 7 = 5 − 3 + 7 = 9.

(ii) p(a) = 4a³ − a² + 6.

Question 3. A number multiplied by 5/2 and then increased by 2/3 gives −7/12. Find the number.

Show Solution

Let the number be x.

(5/2)x + 2/3 = −7/12.

(5/2)x = −7/12 − 8/12 = −15/12 = −5/4.

x = (−5/4)(2/5) = −1/2.

Question 4. One positive number is five times another. After adding 21 to both, the larger new number is twice the smaller new number. Find them.

Show Solution

Let the smaller number be x. The larger is 5x.

5x + 21 = 2(x + 21).

5x + 21 = 2x + 42, so 3x = 21 and x = 7.

Answer: 7 and 35.

Question 5. Start with ₹800 and save ₹250 every month. Find the amount after 6 months and 2 years.

Show Solution

After n months: A = 800 + 250n.

After 6 months: 800 + 250(6) = ₹2300.

After 24 months: 800 + 250(24) = ₹6800.

Question 6. The digits of a two-digit number differ by 3. Adding the number to its digit-reversed form gives 143. Find the two numbers.

Show Solution

Let the digits be a and b. The sum of the two numbers is 11(a + b) = 143.

Therefore a + b = 13. Their difference is 3.

The digits are 8 and 5.

Numbers: 85 and 58.

Question 7. For the line y = −3x + 4, identify its slope and y-intercept, and find where it meets the y-axis.

Show Solution

Compare with y = ax + b.

Slope a = −3; y-intercept b = 4.

At x = 0, y = 4.

The line meets the y-axis at (0, 4).

Plot (0, 4), (1, 1) and (2, −2), then join the points.

Question 8. Use y = (9/5)(x − 273) + 32 to convert between Kelvin x and Fahrenheit y.

Show Solution

At x = 313 K:

y = (9/5)(313 − 273) + 32 = (9/5)(40) + 32 = 72 + 32 = 104°F.

At y = 158°F:

158 − 32 = (9/5)(x − 273).

126 × 5/9 = x − 273, so 70 = x − 273.

x = 343 K.

Question 9. Work is force multiplied by distance. If the force is 3 units, write the relationship and find work for distance 2 units.

Show Solution

Let work be w and distance be d.

w = 3d.

For d = 2, w = 3(2) = 6 units.

Plot points such as (0, 0), (1, 3) and (2, 6) and join them.

Question 10. A linear polynomial passes through (1, 5) and (3, 11). Find it.

Show Solution

Let p(x) = ax + b.

a = (11 − 5)/(3 − 1) = 6/2 = 3.

Using (1, 5): 5 = 3(1) + b, so b = 2.

p(x) = 3x + 2.

Question 11. Let p(x) = ax + b and q(x) = cx + d, with p(0) = 5, p(x) − q(x) having zero 3, and p(x) + q(x) = 6x + 4. Find both.

Show Solution

Since p(0) = 5, b = 5.

Let p(x) = ax + 5. From p + q = 6x + 4, q(x) = (6 − a)x − 1.

The difference is p − q = (2a − 6)x + 6.

Its zero is 3, so 3(2a − 6) + 6 = 0.

6a − 18 + 6 = 0, so a = 2.

p(x) = 2x + 5; q(x) = 4x − 1.

Question 12. A chain of hexagons is made with matchsticks. Each new hexagon shares one side with the previous hexagon. Find the matchstick pattern.

Show Solution

The first hexagon needs 6 matchsticks. Each additional hexagon adds 5 because one side is shared.

Pattern: 6, 11, 16, 21, …

For n hexagons: M = 6 + 5(n − 1).

M = 5n + 1.

Question 13. A line p passes through (2, 3) and (6, 11). A parallel line q passes through (4, −1). Find both equations and their x-intercepts.

Show Solution

Slope of p = (11 − 3)/(6 − 2) = 8/4 = 2.

p(x) = 2x + b. Using (2, 3): 3 = 4 + b, so b = −1.

p(x) = 2x − 1.

q is parallel, so its slope is also 2. Using (4, −1): −1 = 8 + b, so b = −9.

q(x) = 2x − 9.

For p's x-intercept: 2x − 1 = 0, so x = 1/2.

For q's x-intercept: 2x − 9 = 0, so x = 9/2.

Intercepts: (1/2, 0) and (9/2, 0).

Question 14. What do all functions f(x) = ax + a, where a > 0, have in common?

Show Solution

Factorise: f(x) = a(x + 1).

At x = −1, f(−1) = a(0) = 0.

Therefore, all their graphs pass through (−1, 0).

Each line has positive slope a and y-intercept a.

Quick Revision

  • Linear polynomial: ax + b, where a ≠ 0.
  • Degree = highest power of the variable.
  • For y = ax + b, slope = a and y-intercept = b.
  • Equal slopes give parallel lines, unless the lines coincide.
  • Linear growth has a positive constant rate of change.
  • Linear decay has a negative constant rate of change.
  • To evaluate a polynomial, substitute the given variable value.
